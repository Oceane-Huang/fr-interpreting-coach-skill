# 应用与发布规范

## 已确认的产品方向

免费、非商业试用起步；手机响应式 H5 加独立后台，后续再考虑小程序。当前产品是本机网页与本地语音／语言模型，不需要云 API。学习者自行导入有权使用的素材。避免会员、支付、复杂题库等与最小训练闭环无关的扩张。

已有项目先调查并延续，不能直接覆盖或另起一个被误称为最新的版本。不把对话中的机器路径、端口、模型和版本当作新环境事实；现场检查 README、配置、启动入口及运行状态。Faster Whisper、Ollama 等是可选实现，不是 Skill 自带能力。

## 关键体验

优先验证手机播放、暂停和录音权限，再接识别与分析。每个录音版本有独立操作；删除放在右上角“…”菜单，可提供撤销。按段按需展示参考译文，不强迫完成全部练习，不把“本地模型未就绪”提示伪装成评价。处理任务应有进度／错误反馈，失败保留已完成的转写和练习。网络上下文需满足浏览器麦克风安全要求；localhost 与远程手机访问分开验证。

应用应明确识别与分析的提供方、数据去向、临时文件清理方式及演示状态。限制上传大小和计算并发；公开部署需补齐访问控制和滥用防护，不能把本机开发服务器直接当正式服务。

## 免费自部署分享（保留的经营思路）

基础本机工具免费，用教程和口译练习示范吸引观众；后续优先通过教师指导、原创材料和省心服务收费。商业转化是待验证假设，不能承诺收益。

先发布已在干净环境验证的操作系统版本。现有 Mac 上能用不代表 Windows 已适配。发布包不带个人路径、练习录音、隐私日志、凭证或未经许可的节目素材。提供环境检查、模型下载进度、启动／卸载说明和常见问题；标明已测试硬件、磁盘需求、实测耗时与限制。源码／模型／依赖各自核对许可，不能用“免费”推断允许再分发或商用。核对实际版本最新官方许可，不把此前选择的模型固定为长期默认。

可将版本包放在正式下载发布页，用公众号统一提供下载、图文教程和安装录屏。公开发布、上传仓库或网盘仍需要用户的相应授权；制作本地包不代表已获发布许可。

先找约 5–10 名目标学习者独立试用，观察安装成功、首次完成练习和持续使用情况。过程内容可围绕：工具演示 → 安装教程 → 教师练习示范 → 定期主题任务。

变现顺序可讨论：
- 优先：小班训练营、教师人工点评、一对一辅导。
- 其次：原创／授权、经过教师校订的专题练习包。
- 验证需求后：付费免安装在线版（需计入算力和维护）、教师或院校课堂版本。
- 可选：部署维护服务，控制售后时间成本。

保留免费基础版本与未来收费服务的区别，不擅自添加付费入口、跟踪、联系方式收集或更改许可证。
